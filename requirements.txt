# embedding isn't stuck on CPU there; onnxruntime-gpu has no macOS wheel,
# so local/dev machines fall back to the plain CPU build. Capped below
# 1.27: PyPI's onnxruntime-gpu switched its default build to CUDA 13.0
# starting at 1.27, which fails to load on the still-common CUDA 12.x
# stack (missing libcublasLt.so.13) -- 1.20-1.26 are the CUDA 12.x builds.
